# Victor Visuals website

Responsive website source for Victor Visuals, covering Digital services (website design and maintenance), Creative services (photography and videography), Technology consulting and workstation setup, About, Portfolio, and quote requests.

## Preview locally

1. Install dependencies with `npm install`.
2. Run `npm run dev`.
3. Open `http://localhost:3000`.

The quote form prepares an email addressed to `victorvisuals.prod@gmail.com`. It does not store or send form data on a server.
